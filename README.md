# 🔐 Jvault - SecureFileEncryption - Java GUI File Encryptor

This is a simple and secure Java Swing-based GUI application to encrypt and decrypt files using AES encryption. Perfect as a cybersecurity mini project or to learn about cryptography in Java.

## 💡 Features
- AES-256 encryption
- File selection GUI
- Password-based encryption
- Logs every action
- Error handling for wrong inputs

## 🛠 Technologies Used
- Java SE
- Java Swing (GUI)
- javax.crypto
- SHA-256 (MessageDigest)


## 🔍 How to Use
- Click **Browse** to choose a file.
- Enter a password.
- Click **Encrypt** or **Decrypt**.
- Check the same directory for `.enc` or `.dec` files.

## 🔒 Cybersecurity Practices
- AES symmetric encryption
- SHA-256 password hashing
- File handling validation
- Activity logging
